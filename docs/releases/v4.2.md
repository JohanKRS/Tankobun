# Tankobun 4.2

Android 10+ · versionCode 47 · signed release APK

## English

- Improved compatibility with user-installed extensions, chapter and volume metadata, page loading, and resumed downloads while respecting source rate limits.
- Added Compact, Balanced, and Extensive cache profiles, with separate controls for covers, navigation data, reader pages, and prefetching.
- Added an optional AniList library refresh when opening the app, preserving pending local changes and respecting server limits.
- Daily chapter checks now include only Reading. Opening manga details refreshes chapter lists older than one day; manual reload remains available.
- Strengthened extension trust, backup and recommendation imports, login validation, and protection against syncing pending changes with another account.
- Refined library navigation and screen-state preservation, with all new interface messages translated into the four supported languages.
- Extension review now matches the installed-extension list and is available directly from manga details. Saved source selections and cached chapters remain available while approval is pending.

After upgrading, previously installed extensions may need an initial trust review. Open Settings → Sources or use Review in manga details. Approval applies to the package and its signing identity; updates signed by the same identity retain it.

## Português (Brasil)

- Melhor compatibilidade com extensões instaladas pelo usuário, dados de capítulos e volumes, carregamento de páginas e retomada de downloads, respeitando os limites das fontes.
- Novos perfis de cache Econômico, Equilibrado e Amplo, com controles separados para capas, dados de navegação, páginas do leitor e pré-carregamento.
- Nova atualização opcional da biblioteca do AniList ao abrir o app, preservando alterações locais pendentes e respeitando os limites do servidor.
- A checagem diária de capítulos agora inclui apenas Lendo. Abrir os detalhes atualiza listas de capítulos com mais de um dia; o recarregamento manual continua disponível.
- Mais proteção na confiança em extensões, importação de backups e recomendações, validação do login e envio de alterações pendentes entre contas.
- Navegação da biblioteca e preservação do estado das telas refinadas, com todas as novas mensagens traduzidas nos quatro idiomas suportados.
- A revisão de extensões agora acompanha o visual da lista de extensões instaladas e pode ser aberta diretamente nos detalhes do mangá. A fonte selecionada e os capítulos em cache são mantidos enquanto a aprovação está pendente.

Após atualizar, extensões já instaladas podem precisar de uma primeira revisão de confiança. Abra Configurações → Fontes ou use Revisar nos detalhes do mangá. A aprovação vale para o pacote e sua identidade de assinatura; atualizações com a mesma assinatura mantêm essa aprovação.

## 简体中文

- 改进对用户安装的扩展的兼容性，包括章节与卷信息、页面加载和下载续传，并遵守来源的请求频率限制。
- 新增节省空间、均衡和大容量缓存预设，可分别控制封面、浏览数据、阅读器页面和预加载。
- 新增打开应用时更新 AniList 书架的可选功能，保留待同步的本地更改，并遵守服务器限制。
- 每日章节检查仅包含“阅读中”的作品。打开漫画详情时会更新超过一天的章节列表，也可随时手动重新加载。
- 加强扩展信任、备份与推荐导入、登录验证，以及防止待同步更改被发送到其他账号的保护。
- 优化书架导航和页面状态保留，所有新增界面消息均已翻译为四种支持的语言。
- 扩展审核现与已安装扩展列表保持一致，也可直接从漫画详情打开。等待批准期间，已选择的来源和缓存章节都会保留。

升级后，已有扩展可能需要首次信任审核。请打开设置 → 来源，或在漫画详情中选择审核。批准与软件包及其签名身份绑定；使用相同签名的更新会保留批准。
