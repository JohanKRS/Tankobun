Two library modes, one shelf.

Tankobun supports local-first use without closing the door on AniList. The Book Club Release adds metadata-only recommendation sharing so friends can preview lists before importing them.

Local library

Track status, score, notes, private flags, progress, and custom lists on this device without signing in.

AniList sync

Connect AniList when you want user-authorized account sync, list import, and remote tracking updates.

Content & sources

Tankobun is a reader and library manager. It does not include manga content, extensions, repositories, or content feeds. Recommendation files include metadata only.

No content bundled

The APK installs Tankobun only. It does not provide manga, chapters, scanlations, source APKs, or source repository URLs.

User-installed sources

Any extension or source setup is managed by the user and stays outside recommendation files and the official update manifest.
